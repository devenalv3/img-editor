# 🖼️ Python Image Editor

A lightweight yet powerful image editor built with Python and OpenCV/Pillow. Edit, enhance, and transform your images with ease.

## ✨ Features
- 🖌️ Draw, paint & annotate images
- 📐 Crop, resize & rotate
- 🎨 Filters & adjustments (brightness, contrast, blur, sharpen)
- 📝 Text overlay with custom fonts
- 💾 Support for PNG, JPG, BMP, GIF formats
- 🔄 Undo/Redo functionality
- 🖱️ Mouse & keyboard controls

## 🛠️ Tech Stack
- **Python 3.12**
- **OpenCV** / **Pillow**
- **Tkinter** (GUI)

## 🚀 Quick Start
```bash
pip install opencv-python Pillow
python main.py
